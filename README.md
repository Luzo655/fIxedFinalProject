# Positivus — лендинг цифрового маркетингового агентства
 
Адаптивная вёрстка одностраничного сайта по макету из Figma. Проект учебный: я старался повторить дизайн как можно точнее, но некоторые моменты всё же не соответствуют макету (подробности в разделе «Известные отличия от макета»).
 
## Что внутри
 
Страница состоит из следующих блоков:
 
1. Шапка с навигацией (на мобильных устройствах бургер-меню)
2. Hero — заголовок, описание, кнопка и иллюстрация
3. Логотипы компаний-партнёров
4. Services — шесть карточек услуг
5. CTA — «Let's make things happen»
6. Case Studies — три кейса
7. Our Working Process — аккордеон из шести этапов
8. Team — карточки сотрудников
9. Contact Us — форма обратной связи
10. Testimonials — слайдер с отзывами
11. Футер с контактами и подпиской на рассылку
